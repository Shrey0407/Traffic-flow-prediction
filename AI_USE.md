## Statement

AI tools (Claude and Claude Code) were used for planning, explanations, scaffolding, drafting code, notebooks, the website and documentation, as listed above. The research question, dataset and segment choice, the model selection rule (lowest validation MAE among trained models, fixed before testing), the decision to stop adding features, the website requirements and every review decision were mine. I ran the pipeline scripts and checked their outputs against the result files. The test set was first run on 2026-10-22, earlier than planned, and the commit "Freeze final model config ... before test run" was in fact made after that run. No model, feature or hyperparameter was changed afterwards. The main result is that no trained model beat the hour-of-week baseline.
